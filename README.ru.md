# ARV — исследование с графом оснований

[English](README.md)

ARV (Assumption–Research–Verification) помогает AI-агенту собирать целостную
рабочую картину из неполных данных и сохранять основания каждого вывода.
В пакет входят skill исследователя, локальный MCP-сервер и граф в SQLite.

Агент читает источники, выдвигает гипотезы и оценивает их смысл. ARV хранит
происхождение наблюдений, объединяет новые основания и пересматривает зависимые
выводы при изменении предпосылки.

## Технический пример

Целевые платформы — Windows, macOS и Linux. Нужен
[uv](https://docs.astral.sh/uv/getting-started/installation/).
Выполните из распакованной папки проекта в PowerShell на Windows или терминале
на macOS/Linux:

```sh
uv sync --frozen
uv run --frozen --offline python examples/quickstart/run.py
```

Первая команда установит Python 3.13 при необходимости и зависимости из lock-файла.
Демо не требует доступа к внешним источникам и ключей моделей. Оно выполняет
заданные вызовы настоящего MCP-сервера; самостоятельное рассуждение модели здесь
не проверяется. Каждый запуск создаёт отдельный демонстрационный граф.

Этот пример проверяет работу API и сохранение графа. Он не устанавливает
преимущество перед обычным агентом. На вымышленных наблюдениях видно, как два наблюдения усиливают одну гипотезу,
почему копия источника не добавляет нового основания и как прямое противоречие
меняет ранее сохранённый вывод. После перезапуска сервера история сохраняется.
Путь к файлам результата появится в терминале.

## Установка в Codex

Сначала выполните `uv sync --frozen`, затем:

```sh
codex plugin marketplace add .
codex plugin add assumption-research-verification@arv-public
```

Также можно установить плагин из каталога ARV в desktop-приложении. В новом
локальном чате вызовите `$assumption-research-verification` и задайте вопрос с
доступными вам источниками. [Подробная установка](docs/installation.md).

## Границы метода

Наблюдения, предположения и гипотезы хранятся отдельно. Повтор одного источника
не считается независимым подтверждением. Противоречие может ослабить гипотезу
и связанные с ней выводы.

Оценки оснований порядковые: это не проценты вероятности и не сертификат
истинности. Агент продолжает отвечать за смысловую оценку источников и выводов.
Превосходство над обычным агентом пока не установлено сравнительным экспериментом.

Сервер графа работает локально, без адаптеров источников и телеметрии. Переданные
ему фрагменты сохраняются в SQLite. AI-приложение, в котором используется плагин,
может обрабатывать вызовы и результаты по собственным правилам работы с данными.
